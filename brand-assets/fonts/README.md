# Fonts

All three are free Google Fonts. Install them on your computer for Canva, Figma, Word or Keynote. In **Google Slides and Docs**, open the font menu, choose **More fonts**, search the name and click it to add it.

| Use | Font | Download |
|---|---|---|
| Headlines and body text (everything) | **EB Garamond** | https://fonts.google.com/specimen/EB+Garamond |
| Logo and the typeset name only | **STIX Two Text** | https://fonts.google.com/specimen/STIX+Two+Text |
| Numbers inside tables and chart axes only | **DM Mono** | https://fonts.google.com/specimen/DM+Mono |

Rules of thumb:
- Never use all caps.
- Never use monospace for headlines, stats or labels.
- Never add a fourth font.

Don't retype the logo. Use the files in `../logos/` instead.
